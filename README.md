# lucianavarandas.com.br

Site da Luciana Varandas, assistência executiva remota. Arquivos estáticos publicados pelo GitHub Pages a partir do branch main.

- Página: `index.html` (CSS e dados estruturados embutidos)
- Script: `assets/js/site.js`, que carrega o GSAP de `assets/js/vendor/` depois que a página abre
- SEO e GEO: `sitemap.xml`, `robots.txt`, `llms.txt`
- Domínio: `CNAME`. O DNS fica na GoDaddy e não deve ter os registros de e-mail alterados.
